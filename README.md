# Retail Sales Analytics

## Project Overview
This project analyzes retail sales data to understand revenue, profitability, product performance, customer contribution, sales channels, and returns.

## Objectives
- Clean and validate the dataset.
- Calculate key business KPIs.
- Identify top-performing products and categories.
- Analyze monthly sales trends and regional returns.
- Provide business insights and recommendations.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis
- Monthly revenue trends
- Profitability by product and category
- Sales channel performance
- Regional return rates
- Top customers and revenue concentration

## Key Findings
- Net revenue was approximately **235.95 million**.
- Estimated gross profit was approximately **29.95 million**.
- Overall gross margin was **12.69%**.
- The top 10 customers contributed approximately **67.05% of net revenue**.
- Tyres generated the highest total profit.
- Services had the highest gross margin at **62.98%**.
- Islamabad had the highest return-flagged transaction rate at **5.39%**.

## Project Files
- `Retail_Sales_Analytics_Complete.ipynb` — complete analysis
- `Phase_1_Retail_Sales_Analytics_Dataset.xlsx` — original dataset
- `retail_sales_outputs/` — cleaned data, reports, and charts generated by the notebook

## How to Run
1. Download the notebook and original dataset.
2. Keep both files in the same folder.
3. Install the required libraries if needed:
   `pip install pandas numpy matplotlib openpyxl`
4. Open the notebook in Jupyter or Google Colab and run all cells.

## Note
Profit figures are estimates based on the available sales and cost data. Return rates are calculated using transaction rows marked as returns, not unique orders.
